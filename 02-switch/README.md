# Switch Statements

In this topic, I learned how to use switch statements in C++ to execute different blocks of code based on the user's choice. I also learned how to combine switch statements with arithmetic operators to build simple interactive programs.

## Concepts Learned
- switch statement
- case and break
- default case
- User input (cin)
- Output (cout)
- Arithmetic operators (+, -, *, /)

## Projects

### 1. Fruit Choice Program
A program that displays different fruits based on the user's menu choice using a switch statement.

### 2. Calculator
A simple calculator that allows the user to:
- Add two numbers
- Subtract two numbers
- Divide two numbers
- Multiply two numbers

## What I Learned
- How to create a menu using switch statements.
- How to take user input and make decisions based on it.
- How to combine switch statements with arithmetic operations.
- The importance of using meaningful variable names.
- How each `case` executes different code depending on the user's choice.

## Skills Gained
- Problem solving
- Decision making in C++
- Writing cleaner and more organized code
