# If Else

## Program 1

### Voter Eligibility Checker

This program asks the user to enter their name and age.

If the user is 18 years or older, it displays that they are eligible to vote.

Otherwise, it tells them they are not eligible.

## Concepts Used

- Variables
- User Input
- If Else Statements
- Comparison Operators
